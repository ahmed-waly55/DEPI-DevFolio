# DevFolio

A clean and responsive portfolio website built with **HTML, CSS, Bootstrap, and Font Awesome**.

## ✨ Features
- Fully responsive layout
- Clean HTML structure
- Bootstrap grid system
- Font Awesome icons
- No JavaScript libraries

## 🛠 Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome

## 🚀 Live Preview
Just open `index.html` in your browser.
